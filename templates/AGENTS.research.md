## 这个文件管什么

做什么、往哪走，全在 `.auto/goal.md` 里——那个文件每次都要重读，我随时可能改。

这里讲的是循环本身：文件各是什么用、起实验要配合哪几步、通知怎么来的。

## 每轮开始

1. 读 `.auto/notes.md` —— 上一轮进展、卡在哪、下一步
2. 读 `.auto/goal.md` —— **每次都要重读**
3. 看 `.auto/runs.csv` —— 哪些实验在跑
4. **需要回溯**之前试过什么时才读 `tree.md`（它会一直变长，别每轮读）

## 一轮的流程

1. 看上一轮的结果（`DONE` / 日志）
2. 按 goal 决定下一步
3. 改代码
4. 起实验验证（下面「服务器与实验」的 4 步，一步都不能少）
5. 更新 `.auto/notes.md`，结束这一轮

没有"做完"这回事——除非我叫停（Esc）。

## 服务器与实验（最关键，一步步照做）

起完实验后，唯一的信号是：**服务器绝对路径下有没有 `DONE`**。

下面 4 步必须全做：

> **为什么强调「服务器上的绝对路径」**：扩展每 60 秒 ssh 上去执行一句
> `test -f <路径>/DONE`，**它只认这一个信号**。相对路径、本地路径它都看不到。

**0. 摸清这台服务器的环境**

不同机器差别很大（裸机 / Slurm / Docker / 云 GPU 平台），起实验前探一下：

```bash
ssh {{SSH_ALIAS}} "which sbatch; which docker; which conda; nvidia-smi -L"
```

按探到的结果自己决定怎么起（需要 conda 就写在命令里：`conda run -n <环境名> python ...`）。
拿不到进程号就让它空着（Slurm 作业号、`docker` 都不算 pid），靠 `DONE` 一样能等到。

> **判断错了不会报错，只会让实验永远没人等**——所以这步别省。

**1. 起实验，并尽量拿到进程号**

```bash
ssh {{SSH_ALIAS}} "cd /项目 && nohup python train.py > /输出目录/log.txt 2>&1 & echo \$!"
```

最后那个数字就是进程号（裸机才有；Slurm / Docker 见上，留空）。

**2. 保证实验结束时会写 `DONE`**

- 最好**改代码**，让它跑完把结果写进 `<输出目录>/DONE`
- 或者命令末尾追加：`... ; touch <输出目录>/DONE`
- `DONE` 里放实验结果——这是唯一的自动信号

**3. 立刻调 `track_run` 登记**

```
track_run(
  path="<输出目录的服务器绝对路径>",
  pid="<第 1 步的进程号>",
  note="一句话：在试什么"
)
```

- pid **可选但强烈建议填**：填了崩了**立刻**通知，不填只能等 72 小时超时
- `track` / `note` 是**可选标签**，原样出现在唤醒消息里：
  ```
  - 完成：/data/.../exp12  [methodA / SYSU / seed0]
  ```
  你被叫醒时一眼知道这是哪条实验，不用回头猜

**4. 之后不用管，扩展每 60 秒盯它**

> ⚠️ **漏掉第 2 步或第 3 步 → 这个实验永远不会有人等它，也不会有任何报错。**

## 收到通知后（完成 / 崩溃 / 超时）

1. 读那个路径下的 `DONE`（崩溃的话读日志定位原因）
2. **把那一行从 `.auto/runs.csv` 删掉**（不删会一直被查）
3. 按 goal 判断结果，决定保留还是回滚
4. 更新 `.auto/notes.md`
5. 起下一个实验（回到上面 4 步）

## 每轮结束必须做

**1. 重写 `.auto/notes.md`**（不是追加，保持精简——它每轮都会被读）：

当前在做什么、正在验证什么、最近结果、下一步打算、哪些不该再试。

**2. 需要回溯时更新 `.auto/tree.md`**（累积记录，按需才读，所以可以详细）：

每试一个新方向追加一个节点，写清：父节点、改动、**commit id**、结果、保留还是回退。

- **commit 建议真的提交**（`git commit -am "..."`）。只记 HEAD 但没提交的话，
  那个节点是**回不去**的——未提交的改动没法恢复。

## 服务器纪律

- **起实验前先查显卡占用**，自己 ssh 查：
  `ssh {{SSH_ALIAS}} "gpustat"`（没装就用
  `nvidia-smi --query-gpu=index,memory.used,memory.total,utilization.gpu --format=csv`）
  只往**确认空闲**的卡上放
- **并发上限见 `.auto/goal.md`**（多人共用的服务器务必设上限，不要占满）
- 不动别人的进程、文件、环境
- 登记超过 72 小时还没有 `DONE` 会被提醒——通常意味着崩了或忘了写 DONE
- 排查问题可以自由用 ssh（看日志、查进程、kill、nvidia-smi），但必须走正门：
  `ssh {{SSH_ALIAS}} '<任意命令>'`
  - 不要用**另一套环境里的 ssh**（比如 `wsl ssh`）——它有独立的钥匙和
    known_hosts，会卡在指纹确认
  - 也不要 `ssh 用户@裸IP`（绕过别名，同样卡交互确认）
